# 하비랑 생산 작업 기록 — GitHub Pages 배포

소스 생산의 출고 → 세척(작업) → 포장을 현장 태블릿·PC에서 입력하고, 작업일지 · 생산일지 · 해당일 기록 · 제품 1차 수량 확인용을 자동으로 만드는 웹앱입니다. (코리아식품 생산 작업 기록과 같은 구성, 로고 · 회사 이름 · 제품 목록만 하비랑)

## 배포 방법 (무료, 약 5분) — 코리아식품과 다른 새 저장소로

1. GitHub → 오른쪽 위 **+** → **New repository**
2. Repository name 예: `habirang-worklog` → **Public** → **Create repository**
3. **uploading an existing file** → 이 폴더의 파일을 **모두** 끌어다 놓기 → **Commit changes**
4. **Settings → Pages** → Branch **main / (root)** → **Save**
5. 1~2분 뒤 주소: `https://<GitHub아이디>.github.io/habirang-worklog/`

같은 GitHub 계정에 코리아식품 사이트가 있어도 괜찮습니다. 하비랑 사이트는 기기 저장 이름과 지문 로그인 등록을 따로 써서 기록이 섞이지 않습니다.

## 로그인

- 아이디 `admin` / 비밀번호 `0123!` (코리아식품과 같음)
- 태블릿 · Windows Hello에서 처음 로그인하면 지문(얼굴) 로그인을 쓸지 묻습니다.

## 기본 목록

- 하비랑 홈페이지 제품 목록 기준: 제품 54종(소스앙 막창소스는 2kg · 50g · 100g 따로, 포장 제품 56개), 구분(기성품 · OEM), 일반제품명, 보관방법, 소비기한(제조일로부터 n개월).
- 공정: 볶음·조림 소스 · 찍먹·버무림 소스 · 비빔 소스 · 육수·원액 · 찌개·전골 소스 · 분말·시즈닝 (메뉴 **수정**에서 바꿀 수 있음).
- 소비기한은 '포장일 + n개월 - 1일'로 자동 제안됩니다. OEM 제품처럼 규격이 없는 제품은 **수정 → 제품**에서 규격을 넣으면 포장 중량이 자동 계산됩니다.

## 꼭 알아 둘 점

- 기록은 각 기기(브라우저)에만 저장됩니다. 여러 기기가 같은 기록을 보려면 별도 데이터 서버가 필요합니다.
- 중요한 기록은 **기록 → 엑셀로 받기**로 백업하세요.
- 시연 후 기록을 비우려면 **설정 → 기록 초기화 → 전체 기록 지우기**.
