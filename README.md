# 하비랑 생산 작업 기록 — CCP 모니터링 (GitHub Pages)

제조공정도(소스류 가열살균 · 비살균, 복합조미식품)와 현장 위치별 CCP 모니터링 일지에 맞춘 웹앱입니다.

## 쓰는 순서

1. **생산계획** — 주간 생산계획표(엑셀)를 올리면 날짜별 생산 목록으로 정리됩니다. ■가열 · □비가열 표시와 제품에 등록한 공정으로 위치별 할 일이 정해집니다.
2. **현장 입력** — 각 위치의 태블릿에서 위치(세척실 · 배합실(가열) · 수분활성도 · 포장실)를 한 번 고르면 다음에도 그 위치로 열립니다. 그날 그 위치에서 할 제품만 보입니다.
   - 세척실 CCP-2B: 원료명 · 세척량 · 세척액 농도 · 침지 시작/종료 · 잔류염소 농도 (측정값은 기준값으로 미리 채우지 않고 직접 입력)
   - 배합실 CCP-1B: 재료 준비 · 배합 · 가열 · 냉각 시간, 85℃ 이상 도달시간, 표시/제품온도, 교반기
   - 수분활성도 CCP-3B: 검사결과(Aw)
   - 포장실 CCP-4P: 포장 정보 · 산출수량 · 수율, 희석 전 품질, 금속검출 점검표
   - 총 배합중량은 한 번 넣으면 모든 일지에 같은 값으로 들어갑니다.
   - 세척 · 가열 기록이 없으면 포장을 저장할 수 없습니다.
   - 켜 둔 한계기준을 벗어나면 이상 발생 내역과 조치사항을 적어야 저장됩니다. (처음 값: 가열 85℃ 이상 · 30분, 세척 100ppm 이상 · 5분, 수분활성도 0.6 이하, 금속 검출 0 — 모두 수정 가능)
3. **일지** — 날짜 · 위치를 고르면 하비랑 일지 양식 그대로 미리보기 · 인쇄 · 엑셀로 받을 수 있습니다. 빠진 기록은 제품명만 채운 빈 양식으로 나옵니다. 사무실에서 확인 후 인쇄해 결재 · 편철하세요.
4. **수정** — 모든 기준 · 목록은 각 칸의 '수정' 단추로 직접 입력해 저장합니다. 법 · 레시피가 바뀌면 회사에서 바로 고칩니다.
   - 제품: 구분, ■가열 · □비가열, 공정, 금속검출 그룹, 보관 · 소비기한, **제품별 기준(레시피)**
   - CCP 기준: 최소 · 최대(이상 · 이하 · 범위) · 단위 · 이름 · 사용 여부 (냉각 온도, 잔류염소, 염도 · 당도 · pH, 포장 온도, 수율 등은 꺼 둔 채로 준비)
   - 금속검출 그룹(시편 Fe · SUS 크기), 선택 목록(보관방법 · 충진기 · 검사 결과 · 제품 구분 · 포장재 · 거래처 · 세척 원료 · 작업자)
   - 공정 이름 · CCP 번호, 계획표 가져오기 규칙
   - 일지 양식: 현재 양식 받기 → 엑셀에서 고치기 → 새 양식 올리기 (값 칸 위치는 그대로)
5. **설정 → 데이터 백업 · 옮기기** — 모든 설정 · 기록 · 일지 양식을 파일 하나로 받고, 새 기기 · NAS 주소에서 불러와 그대로 이어 씁니다.

## 배포 방법 (무료) — 코리아식품과 다른 저장소

1. GitHub → **+** → **New repository** → 예: `habirang-worklog` → **Public** → **Create repository**
2. **uploading an existing file** → 이 폴더의 파일을 **모두** 끌어다 놓기 → **Commit changes**
3. **Settings → Pages** → Branch **main / (root)** → **Save**
4. 1~2분 뒤 주소: `https://<GitHub아이디>.github.io/habirang-worklog/`

이미 올린 저장소가 있으면 `index.html` · `README.md` · 아이콘 파일을 덮어 올리면 됩니다.

## 로그인

- 같은 GitHub 계정의 코리아식품 사이트와 기기 저장 · 지문 등록이 섞이지 않습니다.

## 꼭 알아 둘 점

- 기록은 각 기기(브라우저)에만 저장됩니다. 현장 태블릿과 사무실 PC가 같은 기록을 보려면 공유 데이터 서버가 필요합니다.
- 중요한 기록은 **기록 → 엑셀로 받기**로 백업하세요.
